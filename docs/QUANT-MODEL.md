# 量化模型说明

## 一、两阶段选股流程

```
全市场快照(新浪) ──► 条件过滤 ──► 流动性候选池 ──► 拉取日K(腾讯) ──► 因子打分 ──► 排序输出
      600~1200只        市值/换手/PE      40~100只          150根K线        6因子加权       Top N
```

### 第一阶段：快照粗筛

按成交额降序取前 `scanCount` 只股票（默认 600，上限 1200），依次过滤：

- 价格区间（默认 2–800 元）
- 流通市值区间（默认 20–8000 亿元）
- 总市值区间（默认 0–100000 亿元；荐股榜可自定义）
- 换手率区间（默认 0.5%–30%）
- 当日涨跌幅区间（默认 -8%–9.8%，规避跌停与接近涨停）
- 市盈率上限（默认 150，亏损股 PE ≤ 0 不参与估值打分）
- 板块白名单（沪深主板 / 创业板 / 科创板）
- 剔除 ST、退市标记

通过过滤的股票按成交额取前 `candidates` 只（默认 70）进入技术面计算。

### 第二阶段：技术面因子

对每只候选股拉取 150 根前复权日 K，计算六类因子（0–100）：

| 因子 | 计算方式 | 说明 |
| --- | --- | --- |
| 动量 | `0.65 × 加权涨幅分位 + 0.35 × 区间位置` | 加权涨幅 = 0.6×20日涨幅 + 0.4×60日涨幅；区间位置 = (收盘 − 20日最低) / (20日最高 − 20日最低) |
| 均线结构 | 逐项加分 | 站上 MA20 +34；MA5>MA10 +14；MA10>MA20 +18；MA20>MA60 +22；站上 MA5 +12 |
| 量能 | `0.55 × scale(5日均量/20日均量, 0.55, 1.9) + 0.45 × scale(OBV强度, -0.6, 0.6)` | OBV强度 = 最近5日带方向成交量之和 / (5日均量×5)，同时考虑放量与资金方向 |
| 波动 | `100 − 0.9 × scale(20日年化波动率, 12%, 85%)` | 波动越低越稳定 |
| 估值 | `100 − 85 × PE分位 − (PB>8 ? 15 : 0)` | 亏损股固定 20 分 |
| 成长 | `scale(0.7×净利同比 + 0.3×营收同比, −40%, 90%)` | 取自最新定期报告，缺失时给中性 50 分 |

综合得分：

```
score = Σ(weight_i × factor_i) / Σ(weight_i)
```

权重在页面上可实时调整（0–50），归一化后参与加权，因此调整权重不会改变分数尺度。

### 交易信号

在得分之外，同时输出可解释的信号标签：

- `MACD 金叉`：DIF 上穿 DEA（柱状值由负转正）
- `MACD 红柱放大`：柱状值连续增大
- `均线多头排列`：收盘 > MA5 > MA10 > MA20
- `放量突破`：5 日均量 / 20 日均量 > 1.5 且站上 MA20
- `RSI 超卖 / 超买`：RSI(14) 低于 32 / 高于 72
- `创 20 日新高`：收盘达到 20 日最高价的 99.5% 以上
- `动量强劲`：加权涨幅 > 10%

## 二、策略选股库

系统提供统一 9 个技术策略（`lib/strategies.js`）。荐股榜、个股综合建议、分时买卖点和综合回测共用同一组 key、名称、默认参数及技术字段；日线评分、日频回测和分钟投票按各自周期适配，不直接把不同周期的分数混为一谈。原 8 策略全部保留，新增缠论结构作为第 9 策略；自定义多因子页的波动权重仍是独立筛选工具，不参与统一 9 策略共识。

| key | 策略 | 参考来源 | 评分要点 | 入选阈值 |
| --- | --- | --- | --- | --- |
| `ma_cross` | 双均线趋势 | mementum/backtrader | MA5/MA20 近期金叉、MA20>MA60、趋势结构、MACD、量比与 OBV；RSI 过高降分 | 58 |
| `macd` | MACD 趋势 | mementum/backtrader | DIF/DEA 红柱及放大、MA20/MA60 趋势、量比与 OBV | 56 |
| `momentum` | 动量轮动 | microsoft/qlib | 20/60 日收益、趋势、区间位置、量比与 OBV；RSI 过高、5 日涨幅透支、放量滞涨降分 | 58 |
| `breakout` | 60 日放量突破 | vnpy/vnpy · 海龟交易法则 | 60 日通道、趋势、动量、量比与 OBV；高位突破和短期涨幅过大降分 | 62 |
| `rsi_reversion` | RSI 超跌反转 | mementum/backtrader | RSI 接近超卖线并回升、区间下沿、缩量回踩或 OBV 止跌；弱势资金流降分 | 56 |
| `bollinger` | 布林带回归 | mementum/backtrader | 价格相对中轨位置、企稳回升、MA60、量比与 OBV；接近上轨降分 | 56 |
| `kdj` | KDJ 超跌 | freqtrade/freqtrade 指标组合 | K 值低位、K/D 金叉、RSI 回升与 OBV；K 值高位降分 | 56 |
| `volume_price` | 量价共振 | microsoft/qlib · OBV 量价因子 | OBV 强度、量比、MA20、20 日动量与 MACD；放量滞涨、OBV 背离和缩量上涨降分 | 58 |
| `chan_theory` | 缠论结构 | 公开缠论规则 · 工程化近似 | 最近确认买卖点、新鲜度、确认笔方向、中枢位置与当前结构持仓；仅在右侧确认后生效 | 56 |

### 缠论结构的固定规则口径

`lib/chan.js` 是用于图表和回测的同一纯函数模块，不追求覆盖所有主观缠论流派或完整多级别递归：

- 先按固定方向处理 K 线包含关系，再确认顶 / 底分型；分型需要右侧结构，确认前不生效；
- 由交替、满足最小间隔的分型构造笔，以连续三笔重叠区间近似中枢；
- 用 MACD DIF 背驰、回踩不创新低 / 新高、中枢突破后不回中枢等固定条件近似 1B/2B/3B 与 1S/2S/3S；
- 每个买卖点同时记录 `sourceIndex`（结构极值）与 `confirmIndex`（后续反向锚点确认位置）。`signals` 和图标记仅从确认位置生效，不用未来信息倒填极值日；
- 日 K 只画已确认笔、半透明中枢和确认买卖点，文字面板说明最近笔、中枢区间、价格位置、最近信号及确认日期。

### 板块情绪环境因子

`lib/sector.js` 通过东方财富当前行业名称匹配行业板块，主链路失败时回退 F10 `RPT_F10_CORETHEME_BOARDTYPE`，按行业排名选择 `NEW_BOARD_CODE`。使用板块日 K 计算 0–100 分：趋势 40%、5/20 日动量 35%、量能 25%，映射为「火热 / 活跃 / 中性 / 退潮 / 冰点」。`scoreAt(bars, endIndex)` 只读取 `0..endIndex`，因此实时建议与历史回测可复用同一口径。

环境修正为 `clamp((score - 50) × 0.08, -4, +4)`。实时涨跌家数只展示，不进入历史评分；当前行业归属不代表严格历史成份。行业映射失败时返回中性 50 分和修正 0；行业成功但板块行情失败时保留 `industryName/boardName/boardCode`，仅情绪按 `available:false`、中性 50 分和修正 0 降级，不拖垮九策略主流程。板块情绪不是第 10 个独立买卖策略，不单独触发交易。

- 荐股接口 `/api/recommend` 在扫描池（默认 800 只，可调 200–1200）上先做流动性粗筛，再对候选股计算技术面，最后应用策略评分。
- 输出包含 `score`、`grade`（A ≥ 78 / B ≥ 66 / C）、`reasons`（最多 4 条入选理由）与 `warnings`（风险提示）。
- 同一轮结果内，策略得分基于同一候选池，可横向比较；不同时间因候选池变化不可直接比较。
- 荐股榜单接口 `/api/picks` 不选单一策略，而是对同一候选池同时运行全部 9 个策略：`consensus = 0.72 × 策略平均分 + 0.28 × 命中策略占比 × 100`，按综合分排序输出 Top 20，并附带最佳策略、命中策略数与全市场策略统计。榜单行情每 4 秒轻量刷新，完整排名每 60 秒重算，避免高频触发全市场日 K 扫描。

## 三、多策略综合评分与个股建议

`/api/stock/advice` 对同一只股票同时运行统一 9 个回测策略，用回测质量分配权重：

```
quality_i = (胜率 / 100) × clamp(1 + 区间收益 / 100, 0.1, 4) × clamp(盈亏比, 0.2, 3)
weight_i  = 0.65 × quality_i / Σquality + 0.35 × (1 / N)
```

- 完成交易少于 2 次的策略质量乘以 0.15，少于 4 次乘以 0.6，降低小样本过拟合；
- 与等权基准混合 35%，避免单一策略因短期高胜率占据过高权重；
- 每个策略的当前信号为「持仓（1）/ 空仓（0）」，信号分：持仓 82、空仓 30；最近 2 日新买入信号 +10，新空仓信号 −8；
- 九策略原始分 `rawScore = Σ weight_i × signalScore_i`，最终分 `score = clamp(rawScore + sectorAdjustment, 0, 100)`：≥64 给出「买入」，>44 且 <64 给出「持有」，≤44 给出「卖出」；
- 置信度由多空权重一致性映射到 55%–95%，再按板块环境是否顺向作有界微调，同时输出原始分、最终分、板块调整、策略分歧与弱策略提示。

## 四、分时多策略买卖点

`/api/intraday` 在当日分钟序列上运行与荐股、回测一致的 9 个策略，并做加权投票。前 8 个策略直接适配分钟序列；第 9 个缠论票先把分钟快照聚合为 5 分钟 OHLC，再使用右侧确认的买卖点：

| 策略 key | 分钟买入适配 | 分钟卖出适配 | 权重 |
| --- | --- | --- | --- |
| `ma_cross` | MA5 上穿 MA20，且量比 ≥0.95 或 OBV 向上 | MA5 下穿 MA20 | 1.4 |
| `macd` | MACD 柱由负转正，且量比 ≥0.9 或 OBV 向上 | MACD 柱由正转负 | 1.2 |
| `momentum` | 10 分钟动量转正、价格站上 MA20，量比/OBV 确认 | 10 分钟动量转负且价格跌破 MA20 | 1.0 |
| `breakout` | 放量突破前 20 分钟高点且 OBV 向上 | 放量跌破前 20 分钟低点 | 1.3 |
| `rsi_reversion` | RSI 从 30 下方回升 | RSI 从 70 上方回落 | 1.2 |
| `bollinger` | 从布林下轨外收回轨内 | 从布林上轨外收回轨内 | 1.2 |
| `kdj` | K<25 时 K 上穿 D | K>75 时 K 下穿 D | 1.1 |
| `volume_price` | 5 分钟 OBV 斜率转正、价格高于 VWAP 且量比 >1.15 | OBV 斜率转负、价格低于 VWAP 且量比 >1.15 | 1.3 |
| `chan_theory` | 5 分钟确认 1B/2B/3B，映射到确认分钟 | 5 分钟确认 1S/2S/3S，映射到确认分钟 | 1.3 |

- 板块情绪只作环境展示，不独立产生投票，也不放宽以下任何门槛；
- 至少两个策略同向，最强方向加权分 ≥2.2，且达到反向分数的 1.2 倍；
- 买卖点必须交替，相邻标记至少间隔 10 分钟；
- 高位防追买：RSI>70、5 分钟涨幅 >1.5%、高于 VWAP 超过 1.8%，或当日高位急涨时直接拦截；近 20 分钟高位或明显偏离均价的买点，须至少 3 个策略且强度 ≥3.2；
- 低位防杀跌：RSI<32、5 分钟跌幅 >1.2%、低于 VWAP 超过 1.2%、接近日内低点或近 20 分钟低位下跌时直接拦截；其他弱势低位卖点须至少 3 个策略且强度 ≥3.2；
- `blockedBuy` / `blockedSell` 分别记录被高位、低位保护拦截的候选信号数；这些约束只能减少明显追涨杀跌，不能保证每对买卖标记盈利；
- 当前结论结合价格/VWAP、MA5/MA20、MACD、RSI、昨收、量比与 OBV，输出「偏多 / 震荡 / 偏空」；
- 页面每 4 秒拉取最新分钟快照并重算买卖点，后端缓存 3 秒；页面隐藏或离开分时视图时暂停。不是逐笔实时推送，公开行情可能延迟；非交易时段展示最近交易日数据。

## 五、持仓诊断

`/api/portfolio/diagnose` 对每只持仓拉取实时快照与 150 根日 K，按以下规则累加得分：

| 条件 | 分值 |
| --- | --- |
| 收盘 > MA20 / 跌破 MA20 | +1 / −1 |
| MA20 > MA60 / 反之 | +1 / −1 |
| MA5 > MA10 > MA20 | +0.8 |
| MACD 红柱 / 绿柱 | +1 / −0.8 |
| 3 日内 MA5/MA20 金叉 / 死叉 | +0.8 / −1.4 |
| RSI ≥ 78 / RSI ≤ 32 | −2 / +0.6 |
| 放量上涨 / 放量下跌 | +1 / −1.5 |
| 接近 20 日新高 | +0.5 |
| 20 日动量为正 / 60 日动量为负 | +0.5 / −0.6 |
| 5 日回撤超过 6% | −1 |
| 持仓浮亏 > 8% / > 15% | −1 / 再 −1 |
| 浮盈 > 25% 且 RSI > 70 | −1 |

信号映射：

| 总分 | 持仓 > 0 | 持仓 = 0 |
| --- | --- | --- |
| ≥ 3.5 | 加仓 | 买入（≥3） |
| 0.5 – 3.5 | 持有 | 观望 |
| −2 – 0.5 | 减仓 | 观望 |
| < −2 | 清仓 | 观望 |

额外强制规则：浮亏超过 12% 且收盘跌破 MA60 时直接给出「清仓」。信号同时附带置信度（55%–95%）、风险等级、支撑位（MA20/20 日低点）、压力位（20 日高点）、止损位与目标位。

## 六、多策略综合回测

对外 `/api/backtest` 只运行多策略综合建议，不提供单策略或指标参数选择。内部单策略回测仅用于滚动计算质量权重。

- `days` 缺省为 500，仅接受 60–800 的整数；非法输入明确返回 400，不再静默钳制。结果通过 `walkForward.requestedDays` 与 `walkForward.actualTestDays` 分别展示请求天数和受历史数据长度约束后的实际交易日数；
- 一次加载回测期、指标预热与训练数据，预计算九策略因果信号和板块历史分；
- 每 20 个交易日调权，在调权日只读取截至前一交易日、最多 400 日的历史结果，仍按 65% 质量 + 35% 等权平滑，调权间冻结权重；
- 每日按实时建议相同的持仓 / 空仓基础分合成 `rawScore`，叠加板块 ±4 分修正；≥64 切换为持仓，≤44 切换为空仓，中间保持原状态；
- 信号在第 `i-1` 日收盘后确认，统一于第 `i` 日开盘成交，避免用信号日收盘撮合造成前视偏差；期末按最后收盘价强制平仓；
- A 股 100 股整手，全仓进出；旧 `strategy` 和单策略参数在对外接口中无效。

### 指标定义

- 总收益率 = 期末权益 / 初始资金 − 1
- 年化收益 = (1 + 总收益)^(252 / 交易日数) − 1
- 最大回撤 = 权益曲线相对历史峰值的最大跌幅
- 夏普比率 = 日收益均值 / 日收益标准差 × √252（未扣无风险利率）
- 胜率 = 盈利平仓次数 / 平仓次数
- 盈亏比 = 盈利交易总额 / 亏损交易总额（无亏损时封顶 9.99）
- 平均盈利 / 平均亏损 = 每笔盈利（亏损）交易的平均收益率
- 仓位暴露 = 持仓交易日数 / 回测交易日数
- 基准收益 = 同期买入并持有该股票的收益率

## 七、模拟交易

- 初始资金 100 万元，账户保存在浏览器 `localStorage`（key：`money.paper.v1`）。
- 买入需为 100 股整数倍，成本价含买入费用；卖出按持仓加权成本计算浮动盈亏。
- 当日盈亏 = Σ (现价 − 昨收) × 持仓数量，仅作估算。
- 所有委托按用户填写的价格即时成交，不排队、不滑点，仅用于策略验证。

## 八、已知局限

- 因子在候选池内做分位归一化，候选池变化会导致得分不可跨轮直接比较。
- 未做行业中性化，强周期行情下估值因子可能系统性偏向银行等低 PE 板块。

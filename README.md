# MONEY · A股量化终端

一个接入公开财经数据源的 A 股量化选股与模拟交易网站。服务端实时聚合腾讯财经、新浪财经与东方财富的行情与财报数据，提供多因子选股、个股技术分析、策略回测和模拟交易能力。

## 功能

| 模块 | 说明 |
| --- | --- |
| 行情总览 | 上证 / 深证 / 创业板 / 沪深300 指数卡与近 60 日走势，涨幅榜、跌幅榜、成交额榜、换手率榜，全市场行情排序分页，并置顶展示实时多策略荐股前 5 名 |
| 荐股榜单 | 同一候选池同时运行 9 个统一技术策略，按平均得分与命中策略数聚合为综合评分，支持股价（元）与总市值（亿元）区间筛选，输出 Top 20、最佳策略与策略命中率；行情每 4 秒更新，完整排名每 60 秒重算 |
| 策略选股 | 内置双均线、MACD、动量、60 日放量突破、RSI、布林带、KDJ、量价共振、缠论结构 9 个策略，可一键切换并自动扫描全市场，同时保留可调权重的自定义多因子模式 |
| 策略荐股 | 按所选策略对全市场流动性股票实时评分，自动输出当日荐股卡片（得分、等级、入选理由），可一键加入持仓 |
| 持仓信息 | 手动添加 / 编辑持仓股票、股数与成本，平台实时诊断并给出买入、加仓、持有、减仓、清仓、观望信号，附置信度、支撑压力、止损目标与组合风险提示 |
| 个股分析 | 多策略综合建议（9 策略加权 + 板块情绪有界修正）、分时 / 日K / 周K 图、5 分钟缠论第 9 票、日 K 缠论笔 / 中枢 / 确认买卖点与文字解读、技术指标与财报摘要 |
| 综合回测 | 只运行多策略综合建议，不提供单策略选择；20 日滚动调权、收盘确认、次日开盘成交，输出收益、回撤、夏普、胜率、权重、净值曲线与逐笔交易 |
| 模拟交易 | 100 万初始资金，按整手买卖，含佣金 / 过户费 / 印花税估算，持仓盈亏与委托记录本地持久化 |

## 数据源

| 用途 | 来源 | 接口 |
| --- | --- | --- |
| 指数与个股实时快照 | 腾讯财经 | `qt.gtimg.cn/q=sh600519,...` |
| 前复权日 / 周 / 月 K 线 | 腾讯财经 | `ifzq.gtimg.cn/appstock/app/fqkline/get` |
| 当日分时数据 | 腾讯财经（失败回退新浪 5 分钟线） | `ifzq.gtimg.cn/appstock/app/minute/query` |
| 全市场行情榜单与排序 | 新浪财经 | `Market_Center.getHQNodeData` |
| 定期报告财务指标 | 东方财富数据中心 | `RPT_LICO_FN_CPD` |
| 当前行业映射、板块快照与日 K | 东方财富 | `push2.eastmoney.com` / `push2his.eastmoney.com`；行业主链路失败回退 F10 `RPT_F10_CORETHEME_BOARDTYPE` |
| 股票代码 / 名称搜索 | 东方财富 | `searchapi.eastmoney.com/api/suggest/get` |

K 线接口带多域名重试，并回退到新浪 K 线；所有上游请求在服务端做 TTL 缓存，失败时回退到最近一次成功结果。详见 [数据源说明](docs/DATA-SOURCES.md)。

## 技术结构

```
server.js            零依赖 Node.js HTTP 服务：静态资源 + JSON API
lib/datasource.js    上游数据抓取、字段归一化、TTL 缓存与降级
lib/indicators.js    MA / EMA / RSI / MACD / ATR / 波动率 / 最大回撤
lib/quant.js         两阶段选股、因子打分、技术面计算、walk-forward 综合回测
lib/strategies.js    原 8 策略 + 缠论结构第 9 策略的评分规则与解释
lib/chan.js          包含处理、确认分型、笔、中枢与 1/2/3 类买卖点近似
lib/sector.js        板块历史评分、实时广度展示与中性降级
lib/advisor.js       个股多策略综合建议 + 板块环境修正 + 持仓诊断
lib/intraday.js      9 策略分时投票、5 分钟缠论与高低位保护
lib/cache.js         带并发合并与陈旧回退的进程内缓存
public/              原生 HTML / CSS / Canvas 前端（无前端框架）
docs/                数据源、因子模型、API 文档
build.sh / run.sh    部署适配脚本
```

无任何 npm 依赖，Node.js 20+ 即可运行。

## 本地运行

```bash
node server.js          # 默认 http://localhost:8000
# 或
PORT=3000 node server.js
```

## 部署

应用为单进程 Node.js 20 服务，使用 `PORT` 环境变量监听 `0.0.0.0`：

```bash
sh build.sh             # 生成 dist/ 运行产物
cd dist && PORT=8000 sh run.sh
```

## 因子模型

选股采用「快照粗筛 + 技术面精算」两阶段流程，六类因子经分位归一化后按权重加权，综合得分 0–100。详见 [量化模型说明](docs/QUANT-MODEL.md)。

## 策略库

策略实现参考了 GitHub 上关注度较高的开源量化项目与公开经典规则，并改写为可直接在 A 股日线 / 快照 / 财报上执行的规则：

| 策略 | 参考来源 | 核心思路 |
| --- | --- | --- |
| 双均线趋势 | [mementum/backtrader](https://github.com/mementum/backtrader) | MA5/MA20 金叉 + MA60 中期确认 + 量能/OBV |
| MACD 趋势 | [mementum/backtrader](https://github.com/mementum/backtrader) | DIF/DEA 金叉、红柱方向 + OBV 过滤 |
| 动量轮动 | [microsoft/qlib](https://github.com/microsoft/qlib) | 20/60 日收益、区间位置与量能，超买和涨幅透支降分 |
| 60 日放量突破 | [vnpy/vnpy](https://github.com/vnpy/vnpy) | 60 日通道突破 + 成交量与 OBV 确认 |
| RSI 超跌反转 | [mementum/backtrader](https://github.com/mementum/backtrader) | RSI(14) 超卖企稳，结合缩量回踩与 OBV |
| 布林带回归 | [mementum/backtrader](https://github.com/mementum/backtrader) | 下轨企稳、中轨兑现，接近上轨不追高 |
| KDJ 超跌 | [freqtrade/freqtrade](https://github.com/freqtrade/freqtrade) | 低位金叉与高位死叉，结合量能确认 |
| 量价共振 | [microsoft/qlib](https://github.com/microsoft/qlib) | OBV、量比与价格同向，放量滞涨和背离降分 |
| 缠论结构 | 公开缠论规则 · 工程化近似 | 包含处理、右侧确认分型、笔、三笔重叠中枢与 1/2/3 类买卖点 |

每个策略结果都带得分、A/B/C 等级与入选理由；页面顶部自动展示当日最符合策略的股票。策略仅在流动性前 600–1200 只股票中评估，结果不构成投资建议。

## 多策略综合建议

个股分析页不依赖单一指标，而是对同一只股票同时运行与荐股榜相同的 9 个回测策略，并按回测质量分配权重：

- 权重 = 胜率 × 盈利质量 × 盈亏比，归一化后与 35% 等权基准混合，降低小样本与单一策略主导；
- 各策略当前持仓 / 空仓信号按权重加权，板块趋势、5/20 日动量与量能形成 0–100 分，仅对综合分作 ±4 分环境修正；
- 输出「买入 / 持有 / 卖出」、原始分、最终分、置信度、多空权重、板块摘要与策略分歧；行业映射失败时按中性 50 分降级，行业成功但板块行情失败时仍展示行业，仅情绪分降级；
- 卡片下方展示每个策略的区间收益、胜率、盈亏比、最大回撤、完成交易数、权重与当前信号。

「分时」图表在同一 9 策略体系上投票，缠论使用分钟线聚合的 5 分钟 OHLC，只有右侧确认的买卖点才成为第 9 票。至少两个策略同向才标注；趋势与突破要求量能或 OBV 确认，并对近 20 分钟高位追买、当日或局部低位杀跌进行拦截。板块情绪只展示，不独立制造买卖点。页面每 4 秒静默拉取最新分钟快照并重算买卖点，后端分钟缓存 3 秒；标签页隐藏或离开分时视图时暂停，不是 Level-2 逐笔推送。

日 K 图叠加已确认缠论笔、半透明中枢与 1B/2B/3B、1S/2S/3S 标记，所有信号落在确认 K 线，不以未来结构倒填极值日。综合回测只提供九策略组合，不进行单策略选择；回测交易日仅接受 60–800 的整数，结果展示实际交易日数。详细公式见 [量化模型说明](docs/QUANT-MODEL.md)。

## 持仓诊断

「持仓信息」栏目支持手动添加股票、股数与成本价，数据保存在浏览器 `localStorage`（key：`money.portfolio.v1`）。服务端对每只持仓拉取实时快照与 150 根日 K，综合均线结构、MACD、RSI、量能、阶段动量与持仓盈亏，输出：

- **买入 / 加仓**：多头排列、MACD 红柱、放量上涨等信号共振
- **持有**：趋势仍在但信号强度一般
- **减仓**：跌破 MA20、死叉、RSI 超买或浮亏扩大
- **清仓**：中期趋势破坏且亏损超过阈值

同时给出置信度、风险等级、支撑位、压力位、止损位、目标位，以及组合层面的集中度与整体亏损提示。诊断每分钟自动刷新，持仓数据不离开浏览器，仅代码与股数发送到服务端计算。
